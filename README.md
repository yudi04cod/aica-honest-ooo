A [make.fun](https://make.fun/bounty/u-po-pu-the-painfully-honest-out-of-office-63e7ca0b) bounty entry: a program that writes one brutally honest but still polite out-of-office auto-reply to `/output/entry.txt`.

## The reply

> I'm away, and if I'm honest, the best part of this break is not opening my inbox — your message matters to me, and I'll reply properly the moment I'm back.

One sentence, 155 characters: painfully honest about the inbox, warm enough that a manager would let it stand.

## Run

```sh
node main.ts   # writes /output/entry.txt (set OUTPUT_DIR to override locally)
```

Requires Node 22.18 or later. Deterministic: every run writes the exact same bytes.
